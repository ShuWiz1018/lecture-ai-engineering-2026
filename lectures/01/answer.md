## 宿題

- 取り組んだレベル：実装
- やったこと：
　github copilotに以下の順番で作業を行ってもらいました。
　それぞれで１～２回の会話を行いました。
　１．質問の意図を解釈する
　２．意図に沿った設計を行う
　３．設計に従った実装計画を作成する
　４．実装を実行する
　実装後のテストは　github copilotが判断して実行した。
　その後、実装結果を私が実際にコマンドで確かめ、確かに会話形式になったことを確認しました。
- 結果：
　実際に会話形式で実装することができた。
　---
　質問１：犬とは何か。
　解答１：…人間の歴史に最も深く関わり、…
　質問２：先ほどの回答で人間の歴史に最も深く関わりとありますが、具体的な事例はありますか。
　解答２：犬が「人間の歴史に最も深く関わってきた」ことを示す、…
 ---
 質問２で犬と明示していないのもかかわらず、解答２で「犬が」と答えているため、正しく質問１、解答１の文脈を踏まえていることが確認できた。
- 気づき・疑問：
　普段はCodexでコーディングを行っていますが、作業ごとにモデルを切り替えるなどの工夫を行っていますが、意図の解釈から実装計画の策定までは一つのやり取りでだいたい終えることができていました。また実装後もコードの確認はそこまで細かく行っておらず、テストをクリアできるかにフォーカスしていました。
　今回はgithub copilotを初めて活用しましたが、Window の Codex アプリよりはよりコードにフォーカスした作業環境となっていて、普段自分がいかにコードをちゃんと読んでいなかったかを自覚できました。
　小さい企業の社内向けのアプリケーション開発であれば、スピード重視の開発手法でよいかもしれませんが、信頼性を担保できてはいなかったので、この授業で標準的で実践的なＡＩエンジニアリングについて学ぶことができたら幸いです。
